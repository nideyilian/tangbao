# 中控台（postprocess）

> 只记录与 `../MASTER.md` 不同的规则。没有差异的章节删除。

## 页面

- 名称：中控台（CompositeWorkspace）
- 用户主任务：配置水印归属与图层式水印预设；中控台是各配置功能的统一入口
- 主行动：左栏作用域树点选节点（切作用域）；水印分区内预设画布编辑（`PresetCanvasEditor`）；
  右区「切换中控台功能」分区导航
- 进入条件：`appMode === 'postprocess'`（Header `SegmentedControl` 显示为「中控台」）；App 对其禁用 `app-shell-with-docked-panels` 留白
- 形态口径：**完全对齐「灵境 · 策略中心」（strategy/center，2026-09-20 登录实测）——左树 + 右内容**。
  左栏「配置资产库」（`ConsoleAssetTree`）= 搜索框 + 「全局默认」总览项 + 项目树
  （节点带覆盖计数徽章，点节点 = 切作用域）；右区 = 当前作用域标题 + 分区导航 + 分区内容。
  水印不是独立页面，而是右区里的**一个功能分区**，与渠道与尺寸 / 输出位置 / 分发平级。
  `src/features/composite/lib/controlConsoleSections.ts` 是唯一的分区注册表
  （顺序即界面顺序，第一个是默认分区）。

## 功能分区（4 个）

| 分区       | 组件                  | 作用域口径                                                                     |
| ---------- | --------------------- | ------------------------------------------------------------------------------ |
| 水印       | `PresetManagementTab` | 归属树负责节点级绑定 + 水印库与画布编辑负责全局（**默认分区**）                |
| 渠道与尺寸 | `MediaSection`        | 全局共享规格；分组头带「N / M 已应用」计数徽章；规格编辑折叠在下段             |
| 输出位置   | `OutputSection`       | **消费作用域**（由左树驱动）：全局层写 `mediaOutputDirs`、节点层写 `byMedia`   |
| 分发       | `DistributionSection` | 纯净版自动伴随 + 分发配置（全局唯一一套，无节点覆盖能力）                      |

### ⚠️ 分区的准入约束（新增分区前必读）

**中控台是所有参数的统一编辑入口，节点级覆盖也在其中编辑。**

这是 2026-09-20 明确的定位：中控台的职责是「控制所有参数」，因此
节点级与全局级**都在这里改**，作用域由**左栏配置资产库树**驱动
（`GLOBAL_NODE_ID` = 全局基线，其余为 `AssetCollection.id`；点树节点 = 切作用域）。
不存在「中控台只能改全局、节点级要去别处」的断层。

但**分区只在节点层真有可覆盖字段时才消费作用域**。当前 `PostprocessNodeOverride`
（ADR-0011 收窄后）只有四个字段：

| 字段                  | 中控台对应分区 | 说明                                     |
| --------------------- | -------------- | ---------------------------------------- |
| `outputDir` / `byMedia` | 输出位置     | ✅ 已接作用域                            |
| `watermarkPresetIds`  | 水印           | ✅ 归属树本身就是节点级编辑面            |
| `enabled`             | —              | 整方向开关，暂未在中控台暴露             |

`distribution` / `autoCompanionClean` / `selectedMediaIds` **不在覆盖字段里** ——
它们在前端只在全局层存在（迁移时被提升到 `promotedGlobals`，属只读存档）。
所以「渠道与尺寸」「分发」两个分区**刻意不消费作用域**（界面上写明「全局一套」）：
给用户一个能选节点、选了却什么都不改变的控件，比不给更糟。

新增分区时的判断顺序：
1. 这个参数在 `PostprocessNodeOverride` 里吗？→ 在 ⇒ 消费工作区作用域；
2. 不在 ⇒ 纯全局分区，界面上写明「全局一套」。

## 页面状态

- 初始：默认落在「水印」分区（`watermark`），三栏装配（归属树 / 水印库 / 画布编辑）。
- 加载：无远端加载；LOGO 资产按需取 object URL。
- 空：水印库为空显示 `EmptyState` 引导（右上角 + 新建）；媒体表为空显示 `EmptyState` 引导。
- 成功：编辑即写对应 store（水印 → `useCompositeV2Store`；渠道/输出/分发 → `usePostprocessMediaStore`）。
- 可恢复错误：导入非预设文件时给出明确对话框说明，不猜测导入；目录选择失败走 toast。
- 不可用：非 Electron 环境下选本地文件夹受限，给出说明。

## 响应式差异

- 375px：多栏堆叠为单栏，画布优先；悬浮工具条转底栏。
- 768px：左栏（文件夹）+ 画布，右栏（图层/规则）转 Drawer。
- 1024px：左/中/右三栏接近完整，缩放控制条常驻。
- 1440px：全宽多栏完整。
- 粗指针：拖拽图层改用方向键微调或工具条按钮；缩放用控件而非滚轮手势。
