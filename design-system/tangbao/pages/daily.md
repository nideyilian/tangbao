# 每日生成（daily）

> 只记录与 `../MASTER.md` 不同的规则。没有差异的章节删除。

## 页面

- 名称：每日生成（DailyWorkspace）
- 用户主任务：**定好每个方向每天出多少图，然后每天看结果、挑掉不好的、把通过的发出去**
- 主行动：左栏项目树点方向（切作用域）；右区三个分区依次走完 ——
  「策略卡」配卡 →「每日任务」配数量与比例 →「预览审核」看当天产出并发布
- 进入条件：`appMode === 'daily'`（Header `SegmentedControl` 显示为「每日生成」）
- 形态口径：与中控台同款 —— **左树 + 右内容**，右区三个分区是同一条流水线的三步，
  不是三个互不相干的功能（所以做成 tab 而不是三个一级页面）。

### 三个分区的关系

```
策略卡（配哪些卡）  →  每日任务（每天出多少、各方向占多少）  →  预览审核（看结果、发布）
        ↓                          ↓                                  ↓
   挂在项目树的方向下        按产品配，多产品各一套            按方向分区，今天出的一起看
```

一次完整的日常：卡只在新增/调整时来一次；数量和比例配一次长期有效；
**每天只看「预览审核」** —— 所以它是默认分区。

### 作用域

左树点的是**方向**（项目树第 3 级）。三个分区共用这一个作用域：

- 点产品线 / 产品 ⇒ 右区汇总显示它下面所有方向（卡片列表 / 比例概览都是汇总视角）；
- 点方向 ⇒ 只显示这个方向的卡、这个方向的比例行、这个方向的产出。

产品不写在卡上，靠 `resolveOwningProductId` 沿树往上推 ——
节点改名或移动之后，卡的归属自动跟着走。

### 不许静默（本页最重要的一条）

排产里所有「少了」，都必须看得见原因：

| 情形                     | 界面表现                                              |
| ------------------------ | ----------------------------------------------------- |
| 方向下有卡但一条都没排到 | 该方向行显示 0 张 + 一句原因                           |
| 卡引用的 SOP 被删了      | 卡片标「SOP 已删除」，不参与抽取，并在跑批结论里点名   |
| 卡挂的方向节点没了       | 同上，标「方向已不存在」                               |
| 比例合计不等于 100       | 比例旁显示折算张数（按权重归一，总数仍凑满）           |
| 当天只跑出一部分         | 预览页显示「计划 N / 已出 M」，差额与原因一起显示      |

「配了 1000 张只出了 700 张」如果不报，用户只会以为系统在偷懒。

### 不做

- 不在本页重配后处理参数（水印 / 输出位置 / 命名）—— 那些在中控台，全应用只有一处能配。
- 不做「关掉应用也自动跑」：本页的每日生成依赖应用在运行（杰哥 2026-09-23 拍板）。
