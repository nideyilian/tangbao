# Agent 工作台（agent）

> 只记录与 `../MASTER.md` 不同的规则。没有差异的章节删除。

## 页面

- 名称：Agent 工作台
- 用户主任务：与 AI 助理对话、衍生命图方案、在对话中浏览和复用生成的图像
- 主行动：底部 `InputBar`（与画廊共用）提交对话；`AssistantActionBar` 选择技能
- 进入条件：`appMode === 'agent'`（Header `SegmentedControl` 切换）

## 页面状态

- 初始：存在会话则渲染 `activeRounds` 消息；无会话显示引导新建。
- 加载：助理运行态显示 `AssistantLoadingPanel`（阶段进度 + 取消）。
- 空：无会话/无消息时显 `EmptyState`。
- 成功：助理结果经 `AssistantResultPanel` 展示（替换/追加/复制提示词、变量词条）。
- 可恢复错误：生成失败 Toast 报摘要，可重试单轮。
- 不可用：无权限模型，始终可用。

## 响应式差异

- 375px：会话侧栏遮罩覆盖（移动端下拉唤出）；聊天区单列；输入条压缩。
- 768px：侧栏可收起，聊天区全宽。
- 1024px：侧栏常驻可停靠。
- 1440px：侧栏 + 宽聊天区，与画廊同宽策略。
- 粗指针：顶栏滚动隐藏手势禁用；侧栏用遮罩而非悬停。
