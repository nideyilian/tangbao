# 0012 水印库按产品隔离（预设带归属产品，库按产品过滤）

- **日期**：2026-09-21
- **状态**：**生效中（已实现）**
- **决策者**：杰哥（产品负责人）
- **相关**：[0002](0002-watermark-ownership-model.md)（水印归属由参数层单点决定）、
  [0003](0003-per-media-override-scope.md)（按渠道覆盖）、TB-067

## 背景

水印库原本是**一个全局数组**（`CompositeV2Preset[]`），与左树选中谁无关：
预设上没有任何「属于哪个产品」的字段，库列表直接渲染全量，
新建也只是往数组末尾追加。

后果：左边点 A 产品、点 B 产品，看到的库**一模一样**；任何一套水印都能被任意产品的方向勾上。
杰哥 2026-09-21 的要求原话：「水印库应改为按产品隔离，即每个产品各自维护独立的水印库，
而不再使用全局通用的一批水印预设……确保产品之间不共用同一套水印预设」。

---

## 一、决策：预设带 `productId`，库按产品过滤（**扁平 + 标签，不分桶**）

**不采用** `Record<productId, CompositeV2Preset[]>`：

1. 归属引用（`params[节点].postprocess.watermarkPresetIds`）存的是 **preset id**；
   分桶后「这套预设现在在哪个桶」要多一层查找，且搬桶就是换 id，已有引用会集体失效；
2. 撤销快照 / 导入导出 / 资产引用扫描（`compositeAssets.ts`）都在遍历这一份数组，
   分桶等于把这几条链路全部改一遍，收益却一样；
3. id 全局唯一本来就保证「不会张冠李戴」—— 隔离要解决的是**看与选**，不是 id 冲突。

「作用域 → 产品」的解析收敛成**一个函数** `resolveOwningProductId`（`projectTree/params.ts`）：
产品节点 = 它自己；方向及更深 = 往上一级；产品线 / 全局默认 / 不存在的节点 = `null`。
界面过滤与存量数据的归属推断共用它 —— 各写一遍遍历，迟早在「产品线层算不算」这类细节上分叉，
而分叉的症状只是「某几个方向的水印莫名少一套」。

## 二、决策：产品线 / 全局默认两层**没有**水印库

水印是**产品的资产**。这两层没有归属对象、也没有可勾的清单（数据层就没有 `byMedia` 那一层），所以：

- 界面上只给一句「水印属于产品 —— 先在左侧选一个产品」，新建 / 导入 / 导出三个入口一律禁用
  （给一个点了没反应的控件比不给更糟）；
- 旧的产品线级 / 全局级清单在升级时**摊到每个产品**，而不是丢弃。

**代价（知情接受）**：「在产品线配一次、整条线所有产品一起继承」的玩法退役 ——
隔离之后水印是产品各自的资产，要改得逐产品改。

## 三、决策：存量数据的一次性迁移分两步，**顺序不可反**

1. **先摊旧清单**：全局基线 / 产品线级 `watermarkPresetIds` → 每个产品各一份（产品自己写过的不动），
   摊完清掉产品线那一格与全局基线。不摊就等于直接抹掉用户已配好的水印（R-63 记的就是这类事故）。
2. **再推断归属**：按「哪个产品的节点**显式**勾过它」归位；**跨产品共用的各复制一份**并把该产品下的
   引用改指到各自的副本（隔离的语义就是互不共用；共用一份等于「改 A 的水印顺手改了 B 的」）；
   没人勾过的保持未分配。

**顺序反了会漏人**：那些「只在全局清单里出现过」的水印会保持未分配，而产出链路按 id 照样找得到它 ——
变成「生成图带了这套水印，而界面上哪儿都没有」，比丢掉更难查。

跑过的标记 `presetProductMigrationVersion` 落盘。**没有标记**的话，用户主动把水印摘出产品的动作会在
下次启动被「自动收回」—— 最难查的那类「我明明删了，它自己又回来了」。

## 四、后果与遗留

- **未分配是合法状态**：升级后没有任何产品的节点勾过的水印落在「未分配」区，
  可单个或一键归到当前产品（否则它会永远用不上、也删不掉）。
- **产出链路不校验产品归属**：`taskPostprocess.ts` 仍按 preset id 全局找预设，所以一旦归属数据是
  「跨产品」的，产出照样会叠上去 —— 界面层已经选不到，但**数据层不拦**。
  要彻底拦需要在产出前加一道「预设属于该节点所属产品」的校验，那会让现有跨产品绑定突然不出图，
  留待单独评估。
- **Excel 导入**（中控台）写 `watermarkPresetIds` 时不校验产品归属，与上一条同源。
- 导入水印文件时，文件里的 `productId` 是**导出方机器上的 id**，本机不存在 ——
  落库前必须改写成本机的当前产品，否则这套水印会归到一个查无此人的产品下（导入完就「消失」）。
