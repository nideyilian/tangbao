# 词条库快速面板规范

## 1. 目标

把词条库侧栏从“缩小版后台”改成创作过程中的快速调用器，让用户在不离开画廊的情况下完成：

1. 找到词条。
2. 单击词条并在面板下方查看对应词库内容。
3. 将词条插入提示词；提示词中存在文本选区时替换选区。
4. 需要编辑、批量处理或维护分组时进入“词条管理”。

衡量标准：首屏只保留一个主流程，常用词条不超过两次点击即可插入；完整管理能力不与调用流程混排。

## 2. 信息架构

### 快速面板负责

- 搜索词条名称、候选值和标签。
- “最近 / 收藏 / 全部”三个快捷视图。
- 单一分组筛选。
- 词条列表与当前选中态。
- 底部只读预览：词条名称、分组、候选值数量、候选值内容。
- 主操作“插入”；提示词编辑器有文本选区时显示“替换选中内容”。
- 底部预览提供明确的“AI 衍生”入口，在右侧栏内展开候选值草稿、参数、结果和规则管理，不打开弹窗。
- AI 结果可追加或替换候选值草稿，并在侧栏内保存回当前词条。
- 收藏切换和“词条管理”入口。

### 词条管理负责

- 新建、编辑、删除、恢复和永久删除词条。
- 分组的新建、重命名、合并、归档和删除。
- 批量移动、加标签、置顶、复制和删除。
- 导入、导出、技能生成批次与归档内容。
快速面板不展示通用编辑表单、批量工具栏、导入导出或回收站；AI 衍生是创作调用流程的一部分，直接在侧栏内完成。

## 3. 交互规则

- 单击词条行：只更新选中态和底部预览，不立即插入，避免误操作。
- 单击行内“插入”：在提示词光标位置插入绑定该词条 ID 的变量。
- 提示词编辑器中存在非折叠选区时：主操作文案改为“替换选中内容”，执行后替换选区。
- 切换筛选后，若当前词条仍在结果中则保持选中；否则选择第一条结果。
- 从提示词中的词条变量反向打开侧栏时，应自动选中并滚动到对应词条。
- 收藏按钮是次级动作，不与主操作争夺视觉权重。
- 键盘焦点可到达搜索、视图切换、分组筛选、词条行、收藏和主操作；焦点样式不可依赖颜色变化之外的隐含状态。

## 4. 视觉与布局

- 面板保持现有可停靠行为和尺寸记忆，避免改变工作区布局习惯。
- 头部只保留标题、数量、“管理”和关闭操作。
- 搜索、快捷视图和分组筛选固定在列表上方。
- 列表为唯一可滚动区域。
- 预览固定在底部，默认展示 3 个候选值，其余用“还有 N 条”收起。
- 列表行最小高度 52px；触控目标不小于 32px；正文不低于 12px。
- 不引入新的品牌色或装饰性渐变，沿用现有设计系统的表面、边框、文字和主色令牌。

## 5. 状态与排序

- 最近：按 `updatedAt` 降序，最多展示 20 条。
- 收藏：只展示 `isFavorite`，置顶优先，其次按 `updatedAt` 降序。
- 全部：置顶优先，其次按 `sortOrder`，最后按 `updatedAt` 降序。
- 搜索对词条名称、候选值和标签进行不区分大小写的包含匹配。
- 分组筛选在快捷视图和搜索之后共同生效。
- 已进入回收站的词条不在快速面板出现。

## 6. 验收条件

- 点击任意词条后，下方预览立即显示该词条的真实候选值。
- “插入”和“替换选中内容”均复用现有提示词变量格式，不破坏词条与提示词的绑定。
- 使用词条后 `usageCount` 增加。
- AI 衍生支持相似度、生成数量、规则选择、追加和替换，并在 API 配置无效时给出可恢复的错误提示。
- 空词库、无搜索结果和空收藏均有明确空状态及可执行下一步。
- 1024px 以下视口仍以可关闭浮层显示；桌面端继续支持左右停靠和宽度记忆。
- TypeScript 构建、现有测试和 UI 静态检测通过。

## 7. 本次不做

- 全局命令面板和智能推荐。
- 候选值的侧栏内编辑。
- 新的后端数据结构或迁移。
- AI 自动排序和语义搜索。

这些能力需要独立验证使用频率，不能为了“更智能”重新把快速面板变复杂。
