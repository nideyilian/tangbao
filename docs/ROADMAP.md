## 非功能目标（长期约束，不随版本变动）

| 目标 | 判据 |
| --- | --- |
| 数据不丢 | 涉及落盘 / 数据库的改动必须有「读失败拒绝写盘」语义与备份 |
| 性能不回退 | 批量出图、滚动、导出期间主线程不得出现长冻结（帧探针验收，不看总耗时） |
| 单一真相源 | 一个事实只有一个家，其它地方只放指针 |
| 门禁可信 | 绿灯必须同时意味着"没写坏"和"真的落地了" |
