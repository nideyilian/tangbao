# 预设尺寸与输出根目录变量设计

## 目标

在预设详情中，将基准宽高输入框替换为固定尺寸下拉选择，并让输出根目录与目录模板、文件名模板共用变量插入和解析能力。

## 交互设计

### 基准尺寸

- 使用一个下拉框替代独立的基准宽、基准高输入框。
- 固定提供以下三个选项：
  - `1280×720`
  - `1080×1920`
  - `800×800`
- 选择选项后，同时更新当前预设的 `baseCanvas.width` 与 `baseCanvas.height`。
- 新建预设仍默认选择 `1280×720`。
- 不提供自定义尺寸入口。

### 输出根目录变量

- 保留现有输出根目录文本输入框和“选择”按钮。
- 输出根目录输入框成为命名变量的第三个插入目标。
- 用户聚焦输出根目录输入框后，点击下方任意内置或自定义变量词条，变量标记插入当前选区或光标位置。
- 目录模板与文件名模板原有的变量插入行为保持不变。
- 通过“选择”按钮取得的目录仍直接写入输入框，用户可以继续在其后添加变量。

## 数据与导出

- 不修改预设数据结构；继续使用 `baseCanvas` 与 `outputRootPath`。
- 导出时使用与命名模板相同的内置变量和当前预设自定义变量解析 `outputRootPath`。
- 仅替换变量标记，不清洗或拆分整个根目录，避免破坏 Windows 盘符、UNC 路径和路径分隔符。
- 解析后的根目录再与目录模板生成的子目录及文件名拼接。
- 未知变量保持原样，与现有命名模板行为一致。

## 测试

- 组件测试验证下拉框只包含三个固定尺寸，并能成对更新宽高。
- 组件测试验证聚焦输出根目录后，变量词条按当前光标或选区插入。
- 路径测试验证内置变量、自定义变量和未知变量在输出根目录中的解析行为。
- 导出运行时测试验证解析后的根目录参与最终路径拼接。
- 运行相关测试、完整测试套件和生产构建。

## 非目标

- 不增加自定义基准尺寸。
- 不调整目录模板、文件名模板或变量词条的视觉样式。
- 不改变已有预设迁移和持久化结构。
