# 图层属性面板 A2 设计

## 目标

将当前杂乱的七列参数网格改为稳定、横向、紧凑的属性栏，并让文字、图片、LOGO 三类图层都支持描边。

## 信息架构

- 左侧图层列表保留现有排序、显隐、锁定、重命名和删除能力。
- 右侧顶部显示当前图层名称、类型标签，以及“显示”“锁定”快捷状态。
- 属性区使用一个连续表面，以留白和竖分隔线分为“内容”“位置与尺寸”“外观”“效果”四组。
- 相关字段成对排列：边距 X/Y、坐标 X/Y、尺寸 W/H。
- 文字图层的内容组显示文字、字体、字号、字重、颜色和对齐；图片/LOGO 显示素材名称与替换/加载操作。
- 外观组显示透明度、旋转；媒体图层额外显示圆角和裁切。
- 效果组固定显示描边与阴影。开关紧邻从属参数；关闭时从属参数禁用。

## 描边行为

- 三类图层共享 `{ enabled, color, width }` 描边数据。
- 新建文字、图片、LOGO 图层默认关闭描边，颜色为 `#111827`，宽度为 `0`。
- 旧数据允许缺少描边字段；界面和渲染均使用同一默认值兼容。
- 文字描边沿用 `strokeText`。
- 图片和 LOGO 在图片绘制后，沿图层矩形或圆角矩形绘制居中描边；描边随输出尺寸等比缩放。

## 响应式与密度

- 控件高度约 28px，标签 11–12px，使用 8px 间距节奏。
- 宽屏保持单行四组；空间不足时属性组自然换行，不产生横向页面滚动。
- 不增加新弹窗、标签页或高级描边选项。

## 验收

- 三种图层切换时四组结构稳定，类型专属字段仅出现在“内容/外观”对应位置。
- 三种图层均可启用描边并在导出渲染中生效。
- 现有图层排序、显隐、锁定、阴影、素材加载与文字编辑行为不回归。
- 组件测试、渲染测试、构建通过，并完成同视口视觉对照。
