# 后处理工作区满高布局设计

## 目标

让后处理工作区从顶部应用栏下方一直延伸到视口底边，消除预设管理页下方的大面积空白，同时保持现有编辑结构和交互不变。

## 布局

- `CompositeWorkspace` 使用视口高度减去应用栏高度作为固定可用高度。
- 工作区自身隐藏溢出，导航标签保持固定，当前标签内容占满其余空间。
- 预设管理页移除强制撑开页面的 `680px` 最小高度，改为在父级可用高度内收缩。
- 画布编辑器同样移除 `680px` 最小高度，填满预设管理页的编辑列。
- 左侧配置栏、LOGO 库和图层面板继续使用各自已有的内部滚动区域。
- 保持画布、浮动工具栏、浮动 LOGO 库和浮动图层面板的位置关系不变。

## 范围

只调整后处理工作区及预设管理页的高度和溢出约束。不重排面板，不改变状态、数据和交互逻辑，不修改普通画布或 Agent 模式布局。

## 验证

- 在常见桌面视口高度下，后处理工作区底边与窗口底边对齐。
- 页面不因预设管理页的固定最小高度产生额外纵向滚动。
- 左侧配置内容较长时仍可在栏内滚动。
- LOGO 库和图层面板保持可见、可操作。
- 批量导出与预设管理标签切换正常。
- 现有相关组件测试通过，并补充布局类名约束测试。
