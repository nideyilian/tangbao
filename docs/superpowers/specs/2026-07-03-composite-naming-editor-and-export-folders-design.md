# 合成预设命名编辑器与导出目录设计

## 目标

简化预设命名配置，统一变量词条交互，并让批量导出的目录结构直接由文件名模板决定。

## 范围

1. 从预设详情界面移除“目录模板”编辑器及目录预览。
2. 将“输出根目录”和“文件名模板”改为富文本编辑器。
3. 变量在编辑器内显示为与画廊一致的词条，并支持：
   - 拖拽移动；
   - 选中后使用 Delete 或 Backspace 删除；
   - 右键转换为当前显示值对应的普通文本。
4. 批量导出时，将文件名模板解析后的完整结果同时用作直属文件夹名和文件名。
5. 画布预览默认使用透明棋盘背景。

## 命名与导出规则

文件名模板在每个导出任务中使用该任务的实际变量值解析，包括日期、渠道、尺寸、预设、序号、源文件、源目录及自定义变量。

解析结果经过现有文件系统非法字符清理后，作为文件夹名和文件名。假设：

- 输出根目录为 `D:\Exports`
- 文件名模板为 `{channel}-{size}-{date}`
- 当前任务变量为 `快手`、`1280x720`、`20260703`

最终路径为：

```text
D:\Exports\快手-1280x720-20260703\快手-1280x720-20260703.jpg
```

文件夹必须是输出根目录的直接子目录，不再叠加旧目录模板。现有同名文件冲突处理保持不变，只对文件名追加序号；文件夹名保持模板解析结果。

## 数据兼容

`subfolderTemplate` 暂时保留在预设数据类型和持久化数据中，以兼容已有预设和历史数据，但界面不再显示、导出运行时也不再读取它。不增加数据迁移，也不清理用户已有值。

## 富文本编辑器

两个编辑器共享同一套最小交互实现：

- 普通文本原样保存。
- `{变量名}` 在界面中渲染为不可直接编辑的词条，词条文字显示当前解析值。
- 插入变量时替换当前选区，未保存有效选区时插入到当前编辑器末尾。
- 拖拽词条后更新模板中变量标记的位置。
- 选中词条后按 Delete 或 Backspace 删除整个变量标记。
- 右键词条将变量标记替换为词条当前显示的解析值，之后该内容不再随变量变化。
- 外部受控值变化时同步编辑器内容，但不得在用户输入过程中破坏光标和选区。
- 输出根目录旁继续保留目录选择按钮；选择目录后以普通文本路径替换编辑器全部内容。

变量按钮仍插入到最近激活的命名编辑器。初始激活目标设为文件名模板，避免已移除的目录模板成为隐式目标。

## 预览

命名预览只保留文件预览。预览显示文件名模板的当前解析结果及 `.jpg` 扩展名；实际导出目录结构由同一个解析结果生成，避免界面预览与运行时规则分叉。

## 画布背景

预设画布编辑器的初始预览背景从白色改为透明棋盘格。现有白色、透明、黑色背景切换功能保持不变，切换顺序从透明开始继续循环。

此变化只影响编辑器预览背景，不改变导出渲染内容。

## 测试

- 富文本辅助函数：模板与词条互转、变量解析、拖拽移动、右键转文本。
- 命名编辑器交互：仅存在两个富文本编辑器；变量插入、删除、拖拽和右键转换会提交正确模板。
- 导出路径：文件名模板的内置变量和自定义变量被解析，直属文件夹名与文件名一致。
- 兼容性：旧 `subfolderTemplate` 的值不会影响新导出路径。
- 画布：首次渲染的 `data-preview-backdrop` 为 `transparent`。
