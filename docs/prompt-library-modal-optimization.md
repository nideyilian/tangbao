# 提示词管理弹窗优化方案

> 对象：`GallerySopBatchModal.tsx`（提示词管理弹窗）
> 状态：**P0 + P1 已实施（2026-08-21）**；P2 待办

## 一、现状分析

弹窗 = 左侧「提示词集目录」+ 右侧「选中提示词集详情」。

**左侧目录**（`promptGroups` 文件夹树 + `recentRuns` 提示词集）
- 文件夹树支持无限嵌套、拖拽排序、右键菜单、剪贴板（复制/剪切/粘贴）、批量移动、搜索、收藏筛选
- 提示词集（run）是每次 SOP 生成自动保存的一条记录，可归入文件夹
- 树相关代码：`promptLibraryTree.ts`（236 行纯函数）+ 弹窗内拖拽/剪贴板/批量移动/持久化逻辑（约 600+ 行）

**右侧详情**
- 每条提示词 = 左侧固定 104px 方块图 + 右侧编辑区
- 图片：`OutputImageThumb` 用 `object-cover` 填满方块 → **被裁剪，且不按真实比例**
- 提示词：`<textarea rows={3} min-h-20 resize-y>` → **默认 3 行，长提示词被截断，需手动拉伸/滚动才能看全**

## 二、方案（按你的三个诉求 + 我的判断）

### 1. 树状结构 → 按生成日期排序的时间线（同意你的判断）

**理由：**
- 提示词集的产生方式天然是**时间流水**（每次生成 = 一条记录，自动保存），检索习惯是"最近生成的往上找"，与文件夹的"人工分类整理"心智不匹配；
- 分类诉求已有替代维度：**收藏**（星标）、**搜索**（名称/内容）、**SOP 来源**、**生成时间**；
- 树的日常维护成本高（想清楚"放哪个文件夹"本身就是负担），且拖拽/嵌套/剪贴板代码占据了弹窗近 1/6 的复杂度，收益不成比例。

**具体改动：**
- 左栏改为**扁平时间线**：全部提示词集按 `getRunUpdatedAt` 倒序（最新的在最上面），每项显示：星标收藏、标题、SOP 名、提示词条数、相对时间（"刚刚 / N 分钟前 / N 天前 / 日期"）
- 保留：搜索框、收藏筛选、新建提示词集、右键菜单（收藏/重命名/复制全部/删除）
- 移除：文件夹树渲染、新建文件夹按钮、文件夹内嵌层级、拖拽/剪贴板 UI（`renderPromptFolderTree` 不再渲染）
- **数据兼容（重要）**：`promptGroups` 树数据**保留不删**（`promptLibraryTree.ts` 原样保留），已有文件夹归属仅作为提示词集的次要标签显示；不做数据迁移，零风险回退
- 批量「移动到文件夹」若保留，用现有 `flatPromptGroups` 扁平下拉（代码已存在，把树的层级前缀 `└` 去掉即可）
- 提示词集数量大时（>200 条）启用虚拟滚动

**保留逃生通道：** 树数据层与工具函数不动，未来若需要分组，可加「时间线 / 分组」双视图切换（复用现有代码），代价极低。

### 2. 右侧提示词完整显示

- `textarea` 从固定 `rows={3}` 改为**自适应高度**（auto-grow：内容多高就多高，默认完整可见、不滚动、不截断），保留 `resize-y` 手动拉伸能力；
- 超长提示词（如 > 400 字）提供「折叠 / 展开」按钮，默认**展开**（保证"完整显示"优先），折叠仅作为浏览长列表时的可选减负；
- 编辑区布局微调：提示词行高随内容增长，来源分组之间的间距逻辑不变。

### 3. 图片卡片跟随真实图片比例

- 左侧图片列从固定 `104px` 方块改为**按真实宽高比**渲染：
  - 用 `<img onLoad>` 读取 `naturalWidth / naturalHeight` 设置容器 `aspect-ratio`（不依赖素材数据链路，通用可靠）；
  - 图片 `object-contain` 完整显示、**不裁剪**（替代现在的 `object-cover`）；
  - 容器宽度随比例自适应（钳制在约 96px ~ 200px），高度上限约 240px（超长图不占满屏）；
  - 竖图给足宽度、横图限制高度，多图时的附加缩略图保持小方块不变。

## 三、实施分级

| 优先级 | 内容 | 改动面 | 风险 |
|---|---|---|---|
| P0 | 图片跟随真实比例 + 提示词完整显示 | 仅右侧条目渲染，约 60 行 | 低 |
| P1 | 左栏时间线化（移除树 UI、扁平倒序列表、相对时间） | 左栏重写 + 测试更新，约 400 行 | 中（数据层保留，可回退） |
| P2 | 时间线/分组双视图切换、虚拟滚动、折叠超长提示词 | 增量 | 低 |
